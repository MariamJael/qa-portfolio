## 🎮 Testing Approach

My testing methodology focuses on system behavior, user experience, and edge-case discovery:

1. Validate core functionality through normal user flows  
2. Identify edge cases and non-standard interactions  
3. Stress test UI and gameplay systems through rapid or unusual input  
4. Reproduce issues consistently with clear steps  
5. Document defects in a structured, developer-ready format  
6. Validate fixes through regression testing

## 🧪 Exploratory Testing (Game Systems)
